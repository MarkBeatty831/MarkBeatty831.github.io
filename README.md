# Mark Beatty — Professional Portfolio

This repository hosts my professional GitHub portfolio for IS 3060 at the
University of Utah. The site introduces who I am, the skills I am building, and
the projects I complete throughout the semester, including the KPMG Group
Project.

**Live website:** https://MarkBeatty831.github.io

## About

I am a sophomore Finance student at the David Eccles School of Business, an
aspiring entrepreneur, and I am especially interested in artificial
intelligence — including training a model of my own.

## Sections

- **About** — major, career direction, and my interest in AI
- **Skills** — leadership and communication, business and professional, and what I am currently learning
- **Projects** — four placeholders that will be replaced with completed coursework
- **Resume** — downloadable PDF (coming soon)
- **Contact** — university email, LinkedIn, and GitHub

## Technologies Used

- HTML5 — semantic structure (`header`, `nav`, `section`, `article`, `footer`)
- CSS3 — custom properties, Flexbox, CSS Grid, and media queries
- JavaScript — automatic footer year and mobile menu behavior
- Git and GitHub — version control
- GitHub Pages — hosting

## File Structure

| File | Purpose |
|------|---------|
| `index.html` | All page content and structure |
| `style.css` | All styling, including the responsive layout |
| `script.js` | Small behavior enhancements |
| `README.md` | This file |

No frameworks or build tools are used. The site is plain HTML, CSS, and
JavaScript, which keeps it fast and makes every part of it easy to explain.

## Responsive Design

The layout uses CSS Grid and Flexbox with breakpoints at 860px and 700px. On
phones the project and skill grids collapse to a single column and the
navigation becomes a toggle menu.

## AI Usage

AI tools were used to help draft and refine the structure and styling of this
site. All content about my background, skills, and goals is my own, and I can
explain how each part of the page is built.
